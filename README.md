# Alyssa Jane Rezada — Portfolio Website

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — website content and sections
- `styles.css` — layout, typography, colors, and responsive styles
- `script.js` — mobile navigation and current-year footer

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub + Vercel
1. Create a GitHub repository (for example, `alyssa-portfolio`).
2. Upload all three website files to the repository root.
3. Sign in to Vercel using GitHub.
4. Choose **Add New → Project**, import `alyssa-portfolio`, and deploy.
5. Vercel will provide a public `*.vercel.app` link.

No build command is required for this static HTML website.

## Before publishing
- Replace the `YOUR PHOTO` placeholder with a professional portrait if desired.
- Confirm company names, role titles, dates, and responsibilities in the Experience section.
- Add confirmed education and certification details.
- Add real screenshots or links for project samples. The current project visuals are illustrative mockups, not screenshots of client systems.
- Review the site and test the email and LinkedIn links.

Do not upload patient information, client records, private company dashboards, or confidential work samples. Use anonymized examples and obtain permission before displaying employer/client materials.


## Privacy-safe project portfolio guidance
The email campaign and Google Apps Script + Slack projects are described as sanitized case studies. Before adding screenshots or code samples, remove or replace:
- Patient/customer names, contact details, photos, IDs, and appointment details
- Company names, internal channel names, private URLs, and confidential campaign content
- Slack webhook URLs, API keys, access tokens, passwords, and environment variables
- Calendar IDs, event IDs, internal email addresses, and other identifying metadata

Use fictional sample data and recreated screenshots where possible. Never publish credentials or live webhook URLs. The current visual mockups are illustrative and are not screenshots of live systems.


The portfolio also includes a graphic design and promotional materials project category. Replace illustrative artwork with approved examples of your own work when ready.
